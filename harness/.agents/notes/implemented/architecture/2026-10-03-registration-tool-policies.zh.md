# Agent Note: 注册身份与最终工具投影

Status: implemented

[English](2026-10-03-registration-tool-policies.md) | 中文

## 问题

作用域注册可覆盖继承工具时，工具名称不能标识其实现。普通提示词 waterfall（瀑布式事件）也不能强制约束最终工具列表：其他监听器可以替换其结果，或不委托而直接返回。

## 决策

ToolRuntime 签发可调用的注册句柄，其背后对应唯一的 runtime 内部记录。身份策略按记录引用准入，并在作用域间取交集。被移除的注册变为非活动状态；即便重新注册同一 definition，也会创建不同记录。注册不复制 definition，也不遍历 schema。策略不尝试隔离同一进程中的任意代码或对象篡改。

ToolRuntime 向执行解析与 schema 授权提供同一组准入记录。每份授权携带不透明身份及注册实例的模型可见字段。SystemPrompt 在普通组装之后强制执行授权；LLM（大语言模型）在中间件之前捕获适用策略，并在适配器分发时对其当前授权取交集。候选名称只能被移除，名称相同但身份不同的授权会被拒绝。投影选择注册实例的 schema，不进行深拷贝或内容比较。没有策略时，普通同名覆盖、请求组装和 schema 处理保留原有行为。

策略与注册贡献随所属 effect 撤销。策略工厂被移除后，已捕获的请求策略仍约束执行中的请求；新组合取得新句柄。runtime 身份不持久化。请求拥有者在记录模型输入前执行策略；分发时再次依据活动注册准入，因此中间件不能重新引入已撤销工具。

## 考虑过的替代方案

**名称允许列表。** 它无法区分获准实现与同名覆盖实现。

**Waterfall 监听器排序。** 外层监听器可在过滤监听器返回后修改结果，短路监听器则可完全绕过该监听器。

**以 definition 快照为授权依据。** 复制 schema 内容不能确立注册身份，还会给不受限制的工具增加处理。递归 clone 实现也会在已支持的超深 schema 上失败。

## 影响

组合拥有者保留官方注册函数返回的注册句柄，而不是按名称查找。通用 runtime 不含产品专用名称。多个策略共享名称时必须共享同一注册身份。同进程插件仍是受信可执行代码；这些策略授权 ToolRuntime 分发，不约束任意 JavaScript 执行。

所属测试覆盖同名覆盖、重新注册、策略交集、effect 清理与转换后投影。既有 5,000 层参数及 PTC 输出 schema 测试保留栈安全行为。真实组合消费方还会依据准入注册，验证首次及后续请求、压缩（compaction）和恢复后的组合。
